# 🏰 DungeonCrawl

**DungeonCrawl** is a fantasy dungeon crawler RPG prototype built with **Python** and **Pygame**.

Explore dangerous dungeon floors, defeat monsters, collect loot, upgrade your hero, open treasure chests, and challenge powerful bosses on your way through a deep 100-floor dungeon.

---

## 🎮 About the Game

DungeonCrawl is a small RPG-style game where the player moves through a tile-based dungeon, encounters enemies, gathers equipment, and becomes stronger over time.

Each dungeon floor contains monsters, treasure chests, guarded areas, and a boss. Defeating the boss allows the player to descend to the next floor. The deeper you go, the more dangerous the dungeon becomes — but the rewards become stronger too.

---

## ✨ Features

- 🧭 Tile-based dungeon exploration
- ⚔️ Monster encounters and combat
- 👹 Boss enemies on dungeon floors
- 📈 Player leveling and experience system
- 🎒 Inventory management
- 🗡️ Weapons, armor, potions, gold, and artifacts
- 💎 Item rarity system
- 🧰 Treasure chests with generated loot
- 🏆 Legendary boss rewards
- 💾 Save and load system
- 🖼️ Pygame-based visual rendering
- 🏰 Dungeon progression up to 100 floors
